# ksuid-rs

[![CI](https://github.com/owpz/ksuid-rs/actions/workflows/ci.yml/badge.svg)](https://github.com/owpz/ksuid-rs/actions/workflows/ci.yml)
[![Go Compatibility](https://img.shields.io/badge/Go%20Compatibility-100%25-brightgreen.svg)](https://github.com/segmentio/ksuid)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A comprehensive, production-ready Rust library for generating and parsing
[KSUIDs](https://github.com/segmentio/ksuid) (K-Sortable Unique Identifiers). This is the Rust
counterpart to [@owpz/ksuid](https://github.com/owpz/ksuid) (TypeScript) — both produce identical
output given the same inputs, with **100% cross-language compatibility**.

## Install

```toml
[dependencies]
ksuid = "0.1"
```

With serde support:

```toml
[dependencies]
ksuid = { version = "0.1", features = ["serde"] }
```

## What is a KSUID?

KSUID is for K-Sortable Unique IDentifier. It is a kind of globally unique identifier similar to a
[RFC 4122 UUID](https://en.wikipedia.org/wiki/Universally_unique_identifier), built from the
ground-up to be "naturally" sorted by generation timestamp without any special type-aware logic.

In short, running a set of KSUIDs through the UNIX `sort` command will result in a list ordered by
generation time.

## Why use KSUIDs?

1. **Naturally ordered by generation time**
2. **Collision-free, coordination-free, dependency-free**
3. **Highly portable representations**

For a deeper read: [A brief history of UUID](https://segment.com/blog/a-brief-history-of-the-uuid/)

## How do KSUIDs work?

Binary KSUIDs are 20-bytes: a 32-bit unsigned integer UTC timestamp and a 128-bit randomly generated
payload. The timestamp uses big-endian encoding, to support lexicographic sorting. The timestamp
epoch is adjusted to May 13th, 2014, providing over 100 years of life. The payload is generated by a
cryptographically-strong pseudorandom number generator.

The text representation is always 27 characters, encoded in alphanumeric base62 that will
lexicographically sort by timestamp.

## Features

- **Generate** cryptographically random KSUIDs
- **Parse and validate** KSUID strings with detailed error reporting
- **Component extraction** — timestamp, payload, raw bytes
- **Navigation** — `.next()` and `.prev()` with wrapping semantics
- **Monotonic sequence generation** — up to 65,536 ordered KSUIDs per seed
- **Sorting utilities** — `sort()`, `is_sorted()`, `compare()`
- **Compressed sets** — delta-encoded storage for efficient KSUID collections
- **Serde support** — optional `Serialize`/`Deserialize` behind a feature flag
- **Nil/Max constants** and `Default` trait support
- **`Copy`, `Clone`, `Eq`, `Ord`, `Hash`** — first-class value type semantics
- **Thread-safe** — `Send + Sync` by design
- **Zero panics** on invalid input — returns `Result` or fallback values

## Usage

### Basic Generation and Parsing

```rust
use ksuid::Ksuid;

// Generate a new KSUID
let id = Ksuid::new();
println!("{}", id); // "0ujsswThIGTUYm2K8FjOOfXtY1K"

// Parse a KSUID string
let parsed = Ksuid::parse("0o5sKzFDBc56T8mbUP8wH1KpSX7").unwrap();
println!("timestamp: {}", parsed.timestamp()); // 95004740
println!("unix time: {}", parsed.time());      // 1495004740

// Safe parsing — returns NIL on error
let safe = Ksuid::parse_or_nil("invalid");
assert!(safe.is_nil());

// FromStr trait
let k: Ksuid = "0ujsszwN8NRY24YaXiTIE2VWDTS".parse().unwrap();
```

### Construction

```rust
use ksuid::Ksuid;

// From timestamp + payload
let k = Ksuid::from_parts(95004740, &[0u8; 16]);

// From raw 20 bytes
let k = Ksuid::from_bytes(&[0u8; 20]);

// From byte slice (fallible)
let k = Ksuid::try_from_bytes(&[0u8; 20]).unwrap();

// OrNil variants — return NIL instead of errors
let k = Ksuid::from_bytes_or_nil(&[0u8; 15]); // wrong length → NIL
let k = Ksuid::from_parts_or_nil(100, &[0u8; 16]);
```

### Navigation

```rust
use ksuid::Ksuid;

let current = Ksuid::parse("0o5sKzFDBc56T8mbUP8wH1KpSX7").unwrap();
let next = current.next(); // "0o5sKzFDBc56T8mbUP8wH1KpSX8"
let prev = current.prev(); // "0o5sKzFDBc56T8mbUP8wH1KpSX6"

// Wraps at boundaries
assert_eq!(Ksuid::NIL.prev(), Ksuid::MAX);
assert_eq!(Ksuid::MAX.next(), Ksuid::NIL);

// Comparison
assert_eq!(current.compare(&next), -1);
assert_eq!(current.compare(&current), 0);
assert_eq!(next.compare(&current), 1);
```

### Monotonic Sequence Generation

```rust
use ksuid::Sequence;

let mut seq = Sequence::new();

for _ in 0..100 {
    let id = seq.next().unwrap();
    println!("{}", id);
}

// Introspection
println!("generated: {}", seq.count());        // 100
println!("exhausted: {}", seq.is_exhausted()); // false

// Bounds
let (min, max) = seq.bounds();
println!("next: {} .. max: {}", min, max);

// Reseed when exhausted
seq.reseed();
```

### Sorting

```rust
use ksuid::{Ksuid, sort, is_sorted};

let mut ids = vec![Ksuid::new(), Ksuid::new(), Ksuid::new()];
sort(&mut ids);
assert!(is_sorted(&ids));
```

### Compressed Sets

```rust
use ksuid::{Ksuid, CompressedSet};

// Compress a collection of KSUIDs
let ids: Vec<Ksuid> = (0..1000).map(|_| Ksuid::new()).collect();
let compressed = CompressedSet::compress(&ids);

println!("raw: {} bytes", ids.len() * 20);       // 20,000 bytes
println!("compressed: {} bytes", compressed.len()); // much smaller

// Decompress
let restored = compressed.to_vec().unwrap();
assert_eq!(ids.len(), restored.len());
```

### Serde Support

```rust
use ksuid::Ksuid;
use serde::{Serialize, Deserialize};

#[derive(Serialize, Deserialize)]
struct Record {
    id: Ksuid,
    name: String,
}

let record = Record {
    id: Ksuid::new(),
    name: "example".into(),
};

// Serializes as 27-char base62 string in JSON
let json = serde_json::to_string(&record).unwrap();
```

### Using as a Database ID

```rust
use ksuid::Ksuid;

// KSUIDs work as string primary keys in any database
let user_id = Ksuid::new().to_string(); // "0o5sKzFDBc56T8mbUP8wH1KpSX7"

// Natural chronological ordering — no extra index needed
// SELECT * FROM users ORDER BY id; -- sorted by creation time!
```

## API Reference

### `Ksuid`

| Method | Description |
|---|---|
| `Ksuid::new()` | Generate with current time + random payload |
| `Ksuid::new_with_time(unix_secs)` | Generate with specific Unix timestamp |
| `Ksuid::from_parts(ts, &payload)` | Construct from timestamp + 16-byte payload |
| `Ksuid::from_parts_or_nil(ts, &payload)` | Same, returns NIL on invalid payload length |
| `Ksuid::from_bytes(&[u8; 20])` | Construct from raw 20-byte array |
| `Ksuid::try_from_bytes(&[u8])` | Construct from byte slice (fallible) |
| `Ksuid::from_bytes_or_nil(&[u8])` | Construct from byte slice, NIL on error |
| `Ksuid::parse(&str)` | Parse 27-char base62 string |
| `Ksuid::parse_or_nil(&str)` | Parse, return NIL on error |
| `.timestamp()` | Raw timestamp (seconds since KSUID epoch) |
| `.time()` | Unix timestamp (epoch + raw timestamp) |
| `.payload()` | 16-byte payload reference |
| `.bytes()` | Full 20-byte value reference |
| `.is_nil()` | True if all zeros |
| `.next()` | Next KSUID (wraps MAX → NIL) |
| `.prev()` | Previous KSUID (wraps NIL → MAX) |
| `.compare(&other)` | Returns -1, 0, or 1 |

### Constants

| Constant | Value |
|---|---|
| `Ksuid::NIL` | All zeros — `000000000000000000000000000` |
| `Ksuid::MAX` | All 0xFF — `aWgEPTl1tmebfsQzFP4bxwgy80V` |

### Traits

`Copy`, `Clone`, `Eq`, `PartialEq`, `Ord`, `PartialOrd`, `Hash`, `Default`, `Display`, `Debug`,
`FromStr`, `AsRef<[u8]>`, `From<[u8; 20]>`, `Send`, `Sync`

### `Sequence`

| Method | Description |
|---|---|
| `Sequence::new()` | New sequence with random seed |
| `Sequence::from_seed(ksuid)` | New sequence from specific seed |
| `.next()` | Next KSUID (`Err` when exhausted) |
| `.count()` | Number of IDs generated |
| `.is_exhausted()` | True after 65,536 IDs |
| `.bounds()` | `(min, max)` of remaining range |
| `.seed()` | Current seed KSUID |
| `.reseed()` | Reset with new random seed |
| `.reseed_with(ksuid)` | Reset with specific seed |

### Utility Functions

| Function | Description |
|---|---|
| `sort(&mut [Ksuid])` | Sort in ascending order (in-place) |
| `is_sorted(&[Ksuid])` | Check if sorted |
| `compare(&Ksuid, &Ksuid)` | Compare two KSUIDs |

### `CompressedSet`

| Method | Description |
|---|---|
| `CompressedSet::compress(&[Ksuid])` | Compress (sorts + deduplicates) |
| `CompressedSet::from_bytes(&[u8])` | Decompress from raw bytes |
| `.to_vec()` | Decompress to `Vec<Ksuid>` |
| `.to_bytes()` | Raw compressed bytes |
| `.iter()` | Iterator over compressed KSUIDs |
| `.len()` | Compressed byte length |
| `.is_empty()` | True if empty |

## Go / TypeScript Compatibility

This implementation maintains **100% compatibility** with:
- [segmentio/ksuid](https://github.com/segmentio/ksuid) (Go reference implementation)
- [@owpz/ksuid](https://github.com/owpz/ksuid) (TypeScript implementation)

Given the same inputs, all three libraries produce identical output.

### Cross-Validation Test Vectors

```rust
// Test Vector: Standard KSUID
let k = Ksuid::from_parts(95004740, &payload);
assert_eq!(k.to_string(), "0o5sKzFDBc56T8mbUP8wH1KpSX7");
// Identical in Go: ksuid.FromParts(time.Unix(1495004740, 0), payload)
// Identical in TS: KSUID.fromParts(95004740, payload)

// Navigation produces identical results
let k = Ksuid::parse("0o5sKzFDBc56T8mbUP8wH1KpSX7").unwrap();
assert_eq!(k.next().to_string(), "0o5sKzFDBc56T8mbUP8wH1KpSX8");
assert_eq!(k.prev().to_string(), "0o5sKzFDBc56T8mbUP8wH1KpSX6");
```

|---|---|
| String encoding | 100% |
| Binary format | 100% |
| Next/prev operations | 100% |
| Component extraction | 100% |
| Sorting order | 100% |
| Roundtrip encode/decode | 100% |
